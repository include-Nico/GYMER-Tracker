# GYMER – deploy su Vercel (sito statico)
1. Crea un repo GitHub e carica TUTTI questi file nella radice (index.html, sw.js, manifest.webmanifest, icons/, favicon.ico, vercel.json).
2. Su vercel.com: Add New > Project > importa il repo. Framework Preset: "Other". Nessun build command.
3. Apri l'URL https:// su telefono: Chrome > "Installa app"; Safari iPhone > Condividi > Aggiungi a Home.
I dati del browser sono separati per dominio: esporta il backup JSON dalla versione vecchia e importalo qui.
